【核心规律】
  标签栏不是固定在某个 y 值上，而是随页面滚动一起上下移动。
  => 必须先把页面滚到「标签栏刚好在屏内」的位置，
     当场 uiautomator dump，取实时坐标，再点。
  => 绝不能复用旧坐标！

【每个标签的 x 中心是固定的】(y 随滚动变)
  看点   x=105
  资讯   x=287
  盘口   x=469
  资金   x=657
  社区   x=845
  简况   x=1084
  财务   x=1173

【实测两次的 y 值差异】
  第一次(页面在F10区): y=504
  第二次(下滑一屏):   y=377
  => 差异 = 100+ 像素，证明 y 确实随滚动变

【正确的操作流程】
  1. 拉同花顺前台 monkey -p com.hexin.plat.android
  2. 滚到目标位置（标签栏在屏内）
  3. uiautomator dump 到 xml
  4. 解析出标签当前 bounds -> 中心坐标
  5. input tap 中心坐标
  6. sleep 5~6 秒等动画完成
  7. 再 dump 取内容

【实测确认的内容(本次验证)】
  点(105,377) -> 看点页: AI策略/个股看点/亮点
    半年报利润承压 / 主业盈利质量偏弱 / 外资股东新进流通前十
    回购失信与现金流压力 / 出海避开国内价格战
    弹性来源、当前关注、影响度、同行对比、去提问
    更新于2026-09-11

【文件】pre.xml(顶部)/p1.xml(下滑一屏)/kd2.xml(误点资讯)/kd3.xml(正确点看点)
