【分时数据接口】
GET https://d.10jqka.com.cn/v6/time/hs_{code}/last.js
Header: Referer: https://stockpage.10jqka.com.cn/
返回字段:
  name 股票名 / pre 昨收 / date 交易日 / rt tradeTime 时段
  data: 分时序列, 逗号分隔
    时分,最新价,成交量,均价,累计量
    例: 0930,2.17,14893361,2.170,6863300
  isTrading 是否交易中

【同花顺 d.10jqka.com.cn 接口家族(统一URL模式)】
  /v6/line/hs_{code}/{周期码}/last.js   K线(周期码见 ths_kline_api_periods.txt)
  /v6/time/hs_{code}/last.js            分时
  History: /v6/line/hs_{code}/{周期码}/{年}/defer/last.js  (历史年度,可试)

【F10公司资料网页(静态可抓)】
GET https://basic.10jqka.com.cn/mobile/{code}/company.html
  编码 UTF-8(不要iconv)  可带UA
  结构: <th>字段</th><td>值</td>
  实测拿到字段:
    市盈率(TTM)=亏损  市净率=56.33
    营业总收入=1.902亿  营收同比=-32.08%
    净利润=8039万     净利润同比=154.36%
    销售毛利率=18.95%  销售净利率=41.64%
    净资产收益率=51.93% 资产负债率=94.01%
    所属区域=浙江省-金华市  所属行业=乘用车
    主营业务=汽车整车研发、制造及销售。
  => 炒股家 F10 页可直接用
