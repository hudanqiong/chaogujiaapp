一、数据源
  URL : https://d.10jqka.com.cn/v6/line/hs_{6位纯代码}/{周期码}/last.js
  Header: Referer: https://stockpage.10jqka.com.cn/
  周期码: 01=日K  11=周K  21=月K
  返回: JSONP, data 以 ';' 分行 ',' 分列
  字段: 日期,开,高,低,收,成交量(股),成交额(元),换手率(%),...
  第8列 = 真换手率
  注: 该接口在 Ubuntu 侧 HTTP 200 可用(10530 字节, num=140);
      东财 push2his 同侧 HTTP 000 不通, 故降级为 fallback。

二、代码改动
  Api.kt: 主链路由东财改为同花顺(thsCode 映射 day/week/month);
          新增 parseThsKline(raw): 剥离 JSONP 前缀解析 data;
          失败/为空时走 fetchKlineFallback 降级(东财/腾讯/新浪)。
  Net.kt: getRaw(url, referer="https://quote.eastmoney.com/")
          新增 referer 参数, 向后兼容。
  StockDetailPage.kt: turnoverEst = 真值优先, 估算兜底。
